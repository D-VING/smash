# SMASH WORLD

3D 파괴 샌드박스 게임입니다. 일반 학교와 일반 도시를 선택하고 여러 도구로 건물과 주변을 파괴할 수 있습니다.

## 실행
- GitHub Pages가 활성화된 저장소라면 `/games/smash-world/` 경로에서 실행할 수 있습니다.
- 로컬 실행은 인터넷 연결이 있는 상태에서 `index.html`을 브라우저로 열면 됩니다. Three.js 모듈을 CDN에서 불러옵니다.

## 조작
- 마우스 왼쪽 클릭: 선택한 도구 사용
- 드래그: 카메라 회전
- 마우스 오른쪽 드래그: 카메라 이동
- 휠: 확대/축소
- 숫자키 1~6: 도구 변경
- N: 낮/밤 전환
- 레이저: 화면을 드래그해 발사

## 도구
폭탄, 야구 배트, 레이저, 운석, 지진, 핵폭탄. 효과음은 Web Audio API로 브라우저에서 합성합니다.

이 프로젝트는 참고 게임의 코드를 복사하지 않고 독자적으로 작성한 구현입니다.
